# 🗂️ HR Workspace — 입퇴사자 관리

소규모 인사·총무 팀(5명 내외)을 위한 웹 기반 업무 공유 앱입니다.
입사자·퇴사자의 업무를 체크리스트로 관리하고, 입·퇴사 일정을 캘린더로 보며, 재직자 현황을 함께 관리합니다.

애플 메뉴 스타일의 UI(라이트/다크 토글), 계정 로그인을 갖추고 있으며
**GitHub + Vercel + Supabase** 스택으로 배포해 어디서나 HTTPS 웹으로 접속합니다.

- **배포(인터넷 웹 접속)**: GitHub→Vercel, 데이터는 Supabase(Postgres) → **[DEPLOY.md](DEPLOY.md)** 참고
- **로컬 개발/데모**: 아래 "빠른 시작"

---

## 빠른 시작 (로컬)

```bash
cd hr-workspace
npm install
cp .env.example .env     # DATABASE_URL(Supabase) 입력 — 또는 USE_PG_MEM=1 로 데모
npm run migrate          # 스키마 생성 + 초기 데이터(505명) 주입 (실제 DB 사용 시)
npm start                # http://localhost:4000
```

> **DB 없이 데모로만 보려면**: `.env` 에 `USE_PG_MEM=1` 설정 후 `npm start`
> (인메모리 Postgres로 부팅 시 자동 시드, 재시작하면 초기화됨)

**환경변수**

| 변수 | 기본값 | 설명 |
|------|--------|------|
| `DATABASE_URL` | — | **Supabase Postgres 연결 문자열(필수)** |
| `SESSION_HOURS` | 12 | 세션 유효시간(시간) |
| `PORT` | 4000 | 로컬 서버 포트 |
| `USE_PG_MEM` | — | `1`이면 인메모리 DB로 데모(개발용) |
| `NODE_ENV` / `VERCEL` | — | Vercel에서 자동 설정 → 보안쿠키·HTTPS 자동 ON |

### 기본 계정 (최초 로그인 후 비밀번호 변경 권장)

| 아이디 | 비밀번호 | 권한 |
|--------|----------|------|
| admin  | admin1234 | 관리자 |
| hr1 / hr2 | hr1234 | 담당자 |
| ga1 / ga2 | ga1234 | 담당자 |

**최초 로그인 시 비밀번호 변경이 강제**됩니다(8자 이상). 이후 변경은 좌측 하단 **⚙️ 설정**에서 합니다.

### 적용된 보안 (기본 강화 세트)
- 세션 쿠키 `HttpOnly`+`Secure`(HTTPS)+`SameSite`, HSTS·CSP 등 보안 헤더
- 로그인 5회 실패 시 15분 잠금(무차별 대입 차단)
- 기본 비밀번호 강제 변경, 세션 12시간 만료
- 전체 변경 이력 감사 로그
- Vercel 배포 시 자동 HTTPS, 로그인 잠금은 Postgres 기반(서버리스 대응) — [DEPLOY.md](DEPLOY.md)

## 화면 구성

| 화면 | 설명 |
|------|------|
| **대시보드** | 재직/휴직 인원, 진행중 입·퇴사 건수, 다가오는 일정, 최근 활동 |
| **입사자 관리** | 입사 예정자 등록 → 구분별 업무 체크리스트 진행 → 입사 확정 시 재직자 현황 자동 반영 |
| **퇴사자 관리** | 퇴사 예정자 등록 → 퇴직 업무 체크리스트 → 퇴사 확정 시 재직자 현황에 퇴직 반영 |
| **캘린더** | 날짜별 입사예정(녹색)·퇴사예정(빨강) 일정 표기, 클릭 시 해당 건 열기 |
| **재직자 현황** | 현재 인원 조회·관리. 상태/분야/소속 필터, 이름·사번·부서 검색 |
| **활동 기록** | 누가 무엇을 했는지 변경 이력 |

### 핵심 동작 — 체크리스트의 "구분"

입사자/퇴사자 등록 시 **구분**(현장 / 본사 / 지원-단시간 / 지원-일반)을 선택하면,
원본 엑셀 규칙 그대로 **해당 구분에 필요한 업무 항목만** 자동으로 나타납니다.
예) `본사` 입사자에게는 PC·사원증·명함 등이 보이고, `현장` 입사자에게는 표시되지 않습니다.

- **평가 예정일** = 입사일 + 3개월 / **평가서 교부일** = 입사일 + 2개월 15일 → 자동 계산
- **입사/퇴사 확정** 버튼을 누르면 재직자 현황에 자동 반영(입사=재직 등록, 퇴사=퇴직 처리)

## 기술 구성

- **호스팅**: Vercel(서버리스) — `api/index.js` 가 Express 앱을 그대로 핸들러로 사용
- **DB**: Supabase(Postgres) — `pg` 클라이언트, 데이터·세션·로그인 잠금 모두 저장
- **인증**: scrypt 비밀번호 해시 + DB 세션 토큰(HttpOnly 쿠키)
- **프론트엔드**: 빌드 과정 없는 순수 ES 모듈 + CSS (`public/`)

```
hr-workspace/
├─ api/index.js           Vercel 서버리스 진입점 (server.js 재사용)
├─ vercel.json            라우팅(모든 요청→Express) + 정적파일 포함 설정
├─ server.js              Express 앱 (API·정적·SPA fallback), 로컬에선 listen
├─ lib/
│  ├─ db.js              Postgres 연결·쿼리 헬퍼 (pg / pg-mem)
│  ├─ schema.sql         Postgres 스키마(DDL)
│  ├─ migrate.js         스키마 생성 + 초기 데이터 시드
│  └─ auth.js            로그인·세션·비밀번호·로그인잠금
├─ seed/employees.json   재직자 초기 데이터(505명)
└─ public/
   ├─ index.html
   ├─ css/style.css      애플 스타일 테마(라이트/다크)
   └─ js/
      ├─ config.js       체크리스트 정의·구분별 활성 규칙(원본 엑셀 반영)
      └─ app.js          SPA(화면/라우팅/모달)
```

## 데이터 백업 / 초기화

- **백업**: Supabase 대시보드 → Database → Backups, 또는 `pg_dump "$DATABASE_URL"`
- **초기화/재시드**: `npm run migrate` (멱등 — 비어 있을 때만 주입). 완전 초기화는
  Supabase에서 테이블 DROP 후 다시 `npm run migrate`.

## 참고
